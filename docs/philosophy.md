# Philosophy

This project exists to make developers faster without removing the thinking that makes them better developers.

The default experience is developer-first: expose facts, relationships, examples, runtime context, and syntax help before generating solutions. AI assistance is available on a continuum, from no model at all, through local explanation and partial completion, to explicit cloud or agent workflows.

Core principles:

- The developer owns the intent.
- Deterministic code intelligence is preferred over model guesses.
- AI should explain, surface, and reduce mechanical work before it writes code.
- Moving upward from assistive behavior to generative behavior requires clear user intent.
- Local models are preferred when they can answer well enough; cloud models are optional escalation.
- The same project intelligence should support manual coding, debugging, review, and agent workflows.
